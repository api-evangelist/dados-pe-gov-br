# Pernambuco Open Data (dados-pe-gov-br)

Pernambuco Open Data is a state government open-data portal for Brazil running **CKAN** (~40 datasets).

**URL:** [https://raw.githubusercontent.com/api-evangelist/dados-pe-gov-br/refs/heads/main/apis.yml](https://raw.githubusercontent.com/api-evangelist/dados-pe-gov-br/refs/heads/main/apis.yml)

## API
- Base: `https://dados.pe.gov.br/api/3/action` · [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://dados.pe.gov.br)
